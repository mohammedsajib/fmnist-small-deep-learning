Fashion-MNIST Small Deep Learning Classifier

A PyTorch-based neural network for classifying Fashion-MNIST images into 10 clothing categories.

Tech Stack
Python
PyTorch
NumPy
Pandas
Scikit-learn
Matplotlib
Seaborn
Model
784 → 512 → 256 → 128 → 10
Activation: ReLU
Normalization: BatchNorm
Optimizer: Adam
Learning Rate: 0.001
Epochs: 15
Batch Size: 256
